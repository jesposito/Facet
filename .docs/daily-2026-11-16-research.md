## Act on this

### 1. Land the coordinated OpenTelemetry 1.47.0 proxy update

- **New advisory:** [GHSA-q7gw-24fr-5p69 / CVE-2026-128085](https://github.com/advisories/GHSA-q7gw-24fr-5p69) is a Moderate denial-of-service issue. Valid U+FFFD runes bypass OpenTelemetry's configured attribute-value length limit, allowing span or log attributes to retain more memory than the operator intended. It affects `go.opentelemetry.io/otel/sdk` **1.46.0**, `sdk/log` **0.22.0**, and `trace` **1.46.0**, all locked as indirect modules in [`docker/caddy/go.mod`](../docker/caddy/go.mod). **1.47.0 fixes all three.** The [OSV record](https://api.osv.dev/v1/vulns/GHSA-q7gw-24fr-5p69) gives affected ranges and the fixed version; the Go proxy confirms the 1.47.0 releases for [`sdk`](https://proxy.golang.org/go.opentelemetry.io/otel/sdk/@latest), [`sdk/log`](https://proxy.golang.org/go.opentelemetry.io/otel/sdk/log/@latest), and [`trace`](https://proxy.golang.org/go.opentelemetry.io/otel/trace/@latest).
- **Work already exists:** Dependabot alerts 127–129 match the three modules in `docker/caddy/go.mod` and name 1.47.0 as the first patched version ([official alerts API](https://api.github.com/repos/jesposito/Facet/dependabot/alerts)). Individual PRs [#538](https://github.com/jesposito/Facet/pull/538), [#539](https://github.com/jesposito/Facet/pull/539), and [#540](https://github.com/jesposito/Facet/pull/540) are open. Their ordinary GitHub checks, including backend/proxy security and both architecture builds, passed; each external **Entire Gates** check failed. The lead is preparing a combined update under **`Facet-1ak`**. Land that coordinated change rather than creating a duplicate.
- **Verification required:** update the three module paths together, then run the Caddy tests, the local go-jose regression tests, reachable `govulncheck`, both architecture builds, packaged smoke tests, and image scans. The default [`docker/Caddyfile`](../docker/Caddyfile) has no tracing configuration or explicit attribute limits, but this watch did not establish whether another compiled configuration path reaches the vulnerable code. Practical reachability remains **unverified**. The green [v3.8.11 security run](https://github.com/jesposito/Facet/actions/runs/43419586783) finished at 12:00 UTC on 2026-11-13, before the advisory's 19:00 UTC publication, so it does not clear this new finding.
