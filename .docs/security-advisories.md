# Dependency and image security status

Checked **2026-11-16**.

## Current results

- **OpenTelemetry GHSA-q7gw-24fr-5p69 / CVE-2026-128085 is the new actionable finding.** The v3.8.11 proxy graph selects `otel/sdk` 1.46.0, `otel/sdk/log` 0.22.0 and `otel/trace` 1.46.0. Valid U+FFFD runes bypass `AttributeValueLengthLimit`, allowing attribute memory retention to exceed the configured bound. The fixed modules are all at 1.47.0. Facet's default Caddyfile does not configure tracing, so practical reachability is unverified; the affected code remains in the compiled standard Caddy module graph. The combined update tracked by `Facet-1ak` moves the seven aligned core, log, metric, SDK and trace modules to 1.47.0. Separate Dependabot PRs [#538](https://github.com/jesposito/Facet/pull/538), [#539](https://github.com/jesposito/Facet/pull/539) and [#540](https://github.com/jesposito/Facet/pull/540) also have their normal CI checks green.
- The combined OpenTelemetry update passed `go test ./... github.com/go-jose/go-jose/v3/...`, `go vet ./...`, a CGO-disabled proxy build, Caddyfile validation and `govulncheck` 1.9.0 in the pinned Go 1.27.4 Bookworm container. Reachable analysis reported **No vulnerabilities found**. An updated OSV query no longer matches OpenTelemetry; only the known imaging and go-jose version matches remain.
- **Node 24.22.3 and minimatch 11.0.8 remain fixed in v3.8.10 and later.** Node 24.22.3 fixes High HTTP/2 and TLS issues, including remotely reachable TLS server crash CVE-2026-126051. Both published architectures and the host's nvm default run 24.22.3; `Facet-95e` is closed. Minimatch's development-only lockfile selects 11.0.8. Its two named public advisories remain unavailable, so former exposure is unverified; `Facet-0w3` is closed.
- **postcss-selector-parser 7.2.1 and the Debian digest refresh are fixed in v3.8.11 through [PR #537](https://github.com/jesposito/Facet/pull/537), merged as `2c347ab`.** The parser update is development-only and its production npm tree is empty. The public GHSA-67xj-gfww-g738 advisory remains unavailable, so former affected-range exposure is unverified. `Facet-8qm` is closed.
- `npm audit --json` returned **zero vulnerabilities** across **464 dependencies** for the locked frontend graph. None of the 63 registry-resolved direct dependency or override names inspected was marked deprecated at its selected or latest version; the two local guarded forks were inspected separately. The audit does not cover runtime, host, external-service or vulnerability-reachability status.
- Baseline OSV queries covered **196 unique Go module/version pairs** from both module manifests and matched imaging, three go-jose/v3 findings and the three OpenTelemetry modules. After the combined update, the same 196-pair query matches only imaging and go-jose/v3. Package matching is not reachability analysis and cannot inspect Facet's local go-jose replacement.
- GitHub Dependabot reported four open alerts: the known imaging TIFF finding and the three transitive OpenTelemetry findings in `docker/caddy/go.mod`. The OpenTelemetry alerts name 1.47.0 as the patched release. The imaging alert has no patched upstream version.
- [Security run 43419586783](https://github.com/jesposito/Facet/actions/runs/43419586783) on `43bf199` (`v3.8.11`) passed frontend checks, backend tests and both reachable Go vulnerability steps before the OpenTelemetry update. [Published-image scan 43422619540](https://github.com/jesposito/Facet/actions/runs/43422619540) passed on that release.
- [PR #533](https://github.com/jesposito/Facet/pull/533), merged as **`25fe89f`** and released in **v3.8.8**, updated Facet to Go 1.27.4 and expanded the local go-jose replacement to cover all three v3 advisories. `Facet-zl8` is closed.
- Local Go checks for this watch ran in Docker because the host has no native Go toolchain. The watcher did not run the full browser suite or rebuild the production image; those remain PR/release checks.

## Local patches

- `frontend/vendor/guarded-braces` and `guarded-deepmerge` retain upstream licences and provenance. Remove them only when the consuming dependency chain provides equivalent protection.
- `docker/caddy/third_party/go-jose-v3` is based on v3.0.5 with RSA bounds, CBC-HMAC empty-input and JSON-depth backports, plus an explicit Unicode conversion bound. CI runs `go test ./... github.com/go-jose/go-jose/v3/...` from the parent `docker/caddy` module.
- Facet's default `docker/Caddyfile` uses plain HTTP `:8080` without `acme_server`, `tls internal` or a tracing directive. The go-jose and OpenTelemetry code is compiled into Caddy but those PKI and tracing paths are not configured by default; custom configurations can enable them.
- `backend/third_party/mailyak-v3` adds SMTP connection/exchange deadlines. It is unrelated to these advisories but is another replacement to review during upgrades.
