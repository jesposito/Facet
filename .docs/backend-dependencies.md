## Local replacements and cautions

- `github.com/domodwyer/mailyak/v3` is replaced by `backend/third_party/mailyak-v3`, based on upstream 3.6.2. It adds a 30-second deadline to the two SMTP senders and has race-enabled tests. Reapply or remove that patch deliberately when PocketBase's mail transport changes.
- go-fitz requires cgo. Alpine development uses `GOFLAGS=-tags=musl`; the Debian production build must not use that tag.
- The old release dates on whatlanggo and imaging do not themselves establish that they are unmaintained or vulnerable. They are simply the latest versions reported by the module proxy.
- `Facet-aqv` tracks GHSA-q7pp-wcgr-pffx in imaging 1.6.2. Facet disables TIFF thumbnail generation and the latest observed backend `govulncheck` passed; that reachability result is not a claim that the upstream advisory is fixed.
