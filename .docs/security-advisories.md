# Dependency and image security status

Checked **2026-11-11**.

## Current results

- `npm audit --json` returned **zero vulnerabilities** across 465 dependencies for the locked frontend graph. None of the 63 direct dependency or override `/latest` records inspected was marked deprecated. The audit does not establish that the older local `node_modules` matches the lockfile.
- An OSV package/version query covered **196 unique direct and indirect Go module/version entries** from both module manifests. It matched imaging 1.6.2 and go-jose/v3 3.0.5. Compress 1.20.2 no longer matches its former advisory. Package matching is not reachability analysis and cannot inspect the fixes in Facet's local go-jose replacement.
- [Security run 42941611668](https://github.com/jesposito/Facet/actions/runs/42941611668) on `28a4daa` (`v3.8.8`) passed frontend checks, backend tests, backend `govulncheck` and proxy `govulncheck`. The proxy step also ran the local go-jose replacement's regression tests.
- [PR #533](https://github.com/jesposito/Facet/pull/533), merged as **`25fe89f`** and released in **v3.8.8**, updated Facet to Go 1.27.4 and expanded the local go-jose replacement to cover all three v3 advisories. `Facet-zl8` is closed. [Release run 42941554396](https://github.com/jesposito/Facet/actions/runs/42941554396) passed both architecture builds, scans, signing and manifest publication.
- [Published-image scan 42568088543](https://github.com/jesposito/Facet/actions/runs/42568088543) originally failed with exactly two HIGH findings: `apt` and `libapt-pkg6.0`, both for CVE-2026-109518. The later [published-image scan 42724230846](https://github.com/jesposito/Facet/actions/runs/42724230846) passed.
- [PR #528](https://github.com/jesposito/Facet/pull/528), merged as `fde26de`, selected Caddy 2.11.9 and compress 1.20.2 and retained smallstep/crypto 0.91.0 with the local go-jose patch. The Dockerfile explicitly upgrades APT during the image build. Local proxy checks, the full security workflow and both architecture image scans and packaged smoke tests passed. `Facet-cyi` is closed.
- Local Go tests and scans were not run by the librarian because the host lacks Go and standalone `govulncheck`; CI and release evidence is cited instead.

## Local patches

- `frontend/vendor/guarded-braces` and `guarded-deepmerge` retain upstream licences and provenance. Remove them only when the consuming dependency chain provides equivalent protection.
- `docker/caddy/third_party/go-jose-v3` is based on v3.0.5 with RSA bounds, CBC-HMAC empty-input and JSON-depth backports, plus an explicit Unicode conversion bound. CI runs `go test ./... github.com/go-jose/go-jose/v3/...` from the parent `docker/caddy` module.
- Facet's default `docker/Caddyfile` uses plain HTTP `:8080` without `acme_server` or `tls internal`. The go-jose code is compiled into Caddy but those PKI paths are not reached by default; custom configurations can enable them.
- `backend/third_party/mailyak-v3` adds SMTP connection/exchange deadlines. It is unrelated to these advisories but is another replacement to review during upgrades.
